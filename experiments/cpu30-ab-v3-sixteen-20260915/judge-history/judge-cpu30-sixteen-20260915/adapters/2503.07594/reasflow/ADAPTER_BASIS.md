# Public-input adapter basis
Runs the original SCAFFOLD implementation for all rounds. The existing linear-regression gradient expresses each public sample gradient exactly using two scalar records per client: X=sqrt(a), y=-(b+z)/sqrt(a), with z=-.25,+.25 and lambda_=0. Original batched gradients and their batch normalization are retained; no objective callback is replaced. Deterministic integer draws select the listed noise record in each round and local step through the original sampler with batch_size=1. Source dtype float64 is preserved. Initial theta and controls are public values; Codex accepts controls0, ReasFlow initial control allocation receives the public value at the next source line (only initial state injection). Original local steps, averaging, persistent controls, and Codex's control recentering execute unmodified. Observation wrappers return the original gradient outputs. Trace snapshots record actual local states and controls; corrected_gradient is original grads (Codex) or the same gradient+controls measurement immediately before the original inline update (ReasFlow), never used to manufacture an update. Synthetic dataset generation is bypassed by supplying public regression arrays. No expected states or private comparisons are used.
