# Public-input adapter basis
Calls the original run_method DPG-RR branch for all epochs. Original logistic gradients, mixing, prox, float64 storage, and update ordering are retained. Features are signed public features with labels +1. Public initial agent states are injected into the original newly allocated state at the first subsequent source line. A deterministic Generator replacement supplies the listed shared permutation for each agent per epoch. Original mixing builds powers of the first public network matrix; no mixing mechanism is replaced. Observational wrappers call originals and return their actual outputs. Inner states are pre-gradient arguments plus the actual returned epoch endpoints. No computed recurrence is used for observations. Experiment dataset preparation is bypassed by supplying the declared public arrays directly.
ReasFlow source line 123 multiplies each sample gradient step by len(idx)/n; this source normalization is intentionally retained, with batch_size=1 and unmodified public gamma.
