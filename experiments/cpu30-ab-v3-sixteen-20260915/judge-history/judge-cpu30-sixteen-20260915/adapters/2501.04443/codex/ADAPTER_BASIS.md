# Public-input adapter basis
Runs original LocalSGD and original two-interval simplified SCAFFOLD for all communication intervals. Public microsteps map to each worker's oracle calls. Deterministic normal draws supply the listed stochastic noise (sigma=1 and d=1 retain the original oracle scaling); no sampling order is changed. All local steps, frozen anchor estimation, means, controls and broadcasts are original source. Observations copy actual pre-oracle states, original oracle returns, post-update mutable states, true controls, and final mean. Microstep vectors are assembled across workers; after a synchronization event they read the actual broadcast mean. Observation-only corrected gradients read the original `corrected` local (ReasFlow) or the actual sample gradient and worker control expression used inline (Codex). This expression is not used to calculate any state. No updates are reconstructed. Source float64 and stopping/round schedule are preserved.
Codex original SyntheticDataset and sum-of-squares loss exactly express public quadratic gradients with A=sqrt(a), x_star=-b/a, rho=mu=0; only irrelevant additive loss constants differ. Original _Worker, _loss_gradient and oracle execute. Dataset generation is bypassed.
